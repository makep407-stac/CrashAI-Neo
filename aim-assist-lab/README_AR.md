# AIM ASSIST LAB

نموذج أولي لتطبيق Android بواجهة عربية ومؤشر عائم قابل للتحريك.

## البناء

يتم بناء APK تلقائيًا عبر GitHub Actions عند كل تحديث للمجلد `aim-assist-lab/` أو عبر التشغيل اليدوي من تبويب Actions. بعد نجاح البناء، نزّل ملف `AIM-ASSIST-LAB-debug-apk` من Artifacts في سجل التشغيل.

## حدود النسخة الحالية

هذه نسخة واجهة/مؤشر فقط. لا تلتقط الشاشة، ولا تتعرف على الرؤوس، ولا تتحكم باللمس، ولا تعدّل آلية التصويب في لعبة أخرى، ولا تضمن هيدشوت.
